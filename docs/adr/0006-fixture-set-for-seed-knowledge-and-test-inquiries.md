# Version seed knowledge and test inquiries as one fixture set outside the PRD

The PRD names behavior classes to verify (routine closure, illness, and meal questions; a missing holiday entry; a meal request needing staff confirmation; clarification; conflicting information; technical failure) but not the concrete fictional policies or parent messages that exercise them. Those concrete texts now live in [test inquiries and seed knowledge](../test-inquiries.md), a design artifact that implementation tickets reference and tests load. The PRD stays the stable behavioral baseline and points to that file instead of carrying sample text; this avoids reopening an approved document whenever a sample is reworded, and it stops implementation from inventing bland, unrepeatable samples at test time.

The fixture set has three tiers. Canonical inquiries are clean wording that maps one-to-one to the PRD cases and drives deterministic tests with controlled model responses and the demonstration script. Realistic inquiries carry the texture of actual parent messages (typos, abbreviations, a child's name, relative dates, two questions in one message, a policy question blended with a request for an exception) and are used for the small live grounding checks. Edge inquiries cover exception pressure, instruction override attempts, off-topic questions, a non-English message, near-duplicate wording for matching counts, and the controlled failure modes. Every row states the expected outcome, the supporting seed entry, and what the answer must not do, so a row doubles as an evaluation record rather than only an input.

The seeded knowledge deliberately omits Veterans Day and Presidents' Day so the decisive missing-holiday demonstration works from the starting dataset. The seed does not contain a visible policy conflict, because every reviewer would otherwise meet an unexplained contradiction; the conflicting-information case is exercised only in a test session that inserts a second, conflicting entry. All names, dates, and contact details are fictional. The set is intentionally small, about thirty rows, in keeping with the three-hour budget; adding rows later does not change the PRD.
